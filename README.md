# LSPedia

LSPedia es un diccionario de Lengua de Señas Peruana desarrollado con HTML, CSS y JavaScript.

## Objetivos

- Buscar palabras.
- Ver el video de la seña.
- Explorar categorías.
- Guardar favoritos.
- Historial de búsqueda.
- Panel de administración.

## Tecnologías

- HTML5
- CSS3
- JavaScript
- Bootstrap 5

Versión 0.2
